# Wedding Moodboard & Auto-Brief Studio

Aplikasi web untuk membuat kolase moodboard (Pengajian, Siraman, dan Hari-H) serta menyusun brief lengkap untuk **Fotografer**, **Videografer**, dan **WCC** secara otomatis sesuai media yang diunggah.

## Struktur Folder
```
├── index.html      # Halaman utama aplikasi
├── css/
│   └── style.css   # Styling & layout
└── js/
    └── app.js      # Logika kolase, K-Means warna, Shazam deteksi lagu, WCC vs Videografer otomatis, & ekspor PNG/PDF
```

## Cara Upload & Aktifkan di GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html`, folder `css/`, folder `js/`, dan `README.md` ke repository tersebut.
3. Buka menu **Settings > Pages**, pilih branch `main` (folder `/ (root)`), lalu klik **Save**.
